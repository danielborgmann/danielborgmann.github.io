Multiplayer, specifically

Networking is the part of this job I keep coming back to, and it started a long time before it was a job.

100 players, live
Lead gameplay programmer on Islands of Nyne, a 100-player battle royale that shipped and ran. Shooting mechanics and network prediction, on a map players moved through constantly.
Server authority
A full extraction-shooter slice in UE5 as sole programmer: client, dedicated server, backend. Inventory that feels instant locally and is still the server's decision.
Bandwidth
Designing what actually goes on the wire. That grid inventory replicates IDs and icon descriptors, not objects, because the naive version does not survive a full server.
From scratch
Wrote a latency-normalised netcode model in a custom C++ and Direct3D 11 testbed: fixed 100 Hz tick, commands and snapshots carrying tick IDs, the server simulating tick N from inputs of tick N-10 so every client feels the same delay regardless of ping, with extrapolation when a command is missing.
2003
First public implementation of server-side reconciliation netcode for Unreal Tournament. Same problem, twenty years earlier.

How I work

Small teams, clear scope, and a rate of output that surprises people. I am usually the whole programming side of a project.

Architect, then delegate

I design the system, break it into tasks, and use AI agents to build most of it while I review, stress test and integrate. The judgement about what to build and how it should be shaped stays mine, and so does the accountability when it goes wrong.

Simple beats clever

The system that survives contact with a live server is usually the boring one. I would rather ship something legible that holds up than something elegant that nobody else can change.

Engine-agnostic

Shipped on Unreal 4 and 5, shipping on Godot, extensive Unity experience, and three engines written from scratch. Picking up an unfamiliar codebase is the normal case, not the risk.

I build my own tools

Beatmap editors, a capture archive, a 3D modeller, project mission control, a Discord agent that runs a tournament community on its own. If the tool that would make the work faster does not exist, I write it.
